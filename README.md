# Mini Hospital Emergency Management System

A Java-based application implementing fundamental Data Structures and Algorithms (DSA) for managing hospital operations, patient records, emergency treatment queues, treatment history, and visit histories.

## Data Structures Implemented
- **Binary Search Tree (BST):** Main Patient Records database.
- **Queue (FIFO):** Emergency Patient Queue.
- **Stack (LIFO):** Completed Treatment History.
- **Singly Linked List:** Patient Visit History.
